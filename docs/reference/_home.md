# Reference & notes

A living reference on evaluating LLM products. This grows: notes as I read and
learn, interview questions and answers refined over time, and an annotated list
of the resources this repository draws on. Everything here is written in
markdown and rendered to an offline page you can open straight off disk — the
same no-install promise the lessons make.

To add to it, drop a markdown file in `notes/` or `interview/` (copy the
`_template.md` next to them) and run `make reference`. The index below and the
offline pages regenerate from your markdown; nothing is maintained by hand
twice.
