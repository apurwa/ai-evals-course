Trace reader and cost waterfall

120 traces from the corpus. Read where the money goes, then answer the harder question: what would you need logged that is not here?

About these numbers

Costs are computed by the real pricing code in agent/tracing.py from token counts that are placeholders, because no model was called. The arithmetic and the shape of the distribution are real; the absolute dollars are not a measurement. Prices in evals/pricing.json are also marked unverified. Latency is not shown at all, because a scripted client returns instantly and publishing that as agent latency would be worse than publishing nothing.
