Track B/Local

Run the real thing

Build the world, run the gates, drive the agent yourself, and generate your own traces. The first two commands need no API key. 

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make check

Use a virtual environment

Install into a venv, not your system or base conda environment. The optional tracing backend pulls in specific protobuf and opentelemetry versions that will happily upgrade whatever else you have installed and break it. If you only want the first few lessons, pip install -r requirements-core.txt installs almost nothing.

What you are working on

the agent under test

A support agent for Wayfarer Supply Co., a fictional outdoor gear retailer with 240 customers, 80 products, and 900 orders. It handles returns, warranties, refunds, and address changes against a written policy, and it is not allowed to move money above its authority.

The world is generated deterministically and its clock is frozen at 2026-08-01. Nothing in the repository reads the system clock. If it did, every return-window calculation would drift and the committed corpus would rot within weeks, which is the sort of thing that quietly poisons an eval suite months after anyone remembers writing it.
